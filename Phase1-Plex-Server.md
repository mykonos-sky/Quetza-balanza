# Phase 1 of Plex Server set-up: The Hardware
## What we currently have
The server we are using to set up Plex is a Dell OptiPlex 7050 with an i5 Intel Pro processor chip.
### OptiPlex 7050 Hardware
+ i5 Intel Pro Processor
+ 250GB SSD
+ 8GB RAM DDR4 x4
+ Integrated GPU

## What we will need to upgrade
+ Add a designated GPU
+ 16GB RAM DDR4 x2
+ 4 SSD drives - set up a RAID 10 configuration
+ Minimumn storage requirement - 2 TB
