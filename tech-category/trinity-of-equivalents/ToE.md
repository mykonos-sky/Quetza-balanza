The Trinity of Equivalents will be a place for me to have common commands translated into the three most common operating systems.
- Windows
- MacOS
- Linux (Debian)

In a way, this is a quick "translation" document where I can find how to execute a task or command in three different languages.
In both work and personal life, I use all three operating systems on the daily. It's nice to learn on all three, but it's easy for me to forget how to "translate" between languages. This is not a catch all nor am I promising it will be kept up to date 24/7.
This is a document after all. 
Documentation ages like fish.

In any case, some of these common commands will be scripts that would be used on a scheduler or cron jobs.
