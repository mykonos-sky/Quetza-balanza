# Plex Server Project - Planning
This project will focus on setting up a Plex server from the hardware up. I will be using [No-Fig-8614's Plex guide][PlexGuide] for this set up.
## Goals
As a result of setting up a Plex server, I would like to learn how to:
+ Understand the hardware needs of a Plex media server.
+ Find the best Linux distribution for the media server and set it up on the server.
+ Learn how to navigate the Plex program.
### Note
This particular guide was originally set up for Windows 10. I understand that there will be differences in the set up process so, to preface, No-Fig-8614's guide will be just that, a guide.
## Phase 1
Look at the current hardwere we have and figure out what we will need to add or change on the server we are using. This phase will also include the actual hardware set up.
## Phase 2
Finding the best Linux disribution for running a media server and setting it up on the server.
## Phase 3
Setting up Plex onto the server and configuring it in a way that works and is right.
'Right' in this context means that it will run as intended and securely.
